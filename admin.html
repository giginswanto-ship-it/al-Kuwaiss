Keamanan Data Biro

Cadangan & Pemulihan Basis Data

Unduh seluruh manifest jamaah, foto galeri, pengumuman, dan riwayat forum ke format file aman JSON.

Ekspor Seluruh Database (.json)

Unduh file cadangan yang memuat seluruh data jamaah 18 angkatan, album Jejak Mabrur, dan info pengumuman ke komputer Anda.

Pulihkan / Impor Database (.json)

Pulihkan data dari file cadangan sebelumnya. Sistem akan otomatis memperbarui database dan menyinkronkan seluruh tampilan.

Ekspor PostgreSQL (.sql)

Unduh file data_lokal.sql terformat resmi PostgreSQL untuk migrasi data ke database live/cloud (Supabase, Neon, VPS, cPanel).

Modul Ekspor & Migrasi Database PostgreSQL

Konfigurasi generator perintah otomatis & unduh skrip data_lokal.sql

Sesuaikan Parameter Server Live Anda:
Perintah 1: Eksekusi File Plain SQL (.sql) — Rekomendasi Menggunakan psql
psql -U username_live -d nama_db_live -f data_lokal.sql
Perintah 2: Eksekusi Format Custom Archive (.dump) Menggunakan pg_restore
pg_restore -U username_live -d nama_db_live -v --no-owner --no-privileges data_lokal.dump
Catatan Penting: Flag --no-owner dan --no-privileges wajib dicantumkan saat melakukan pg_restore agar tidak terjadi error kepemilikan objek database ketika user lokal berbeda dengan user hosting live/production.
